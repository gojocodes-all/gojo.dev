Daar El-Mahfouz

A structured digital home for Qur’an, Arabic and Islamic education—designed to help different learners understand the programmes and register without friction.

  • RoleUX, visual design & frontend
  • TypeEducational platform
  • StackReact, Vite, CSS
  • StatusLive

The challenge

The institution offers far more than one class. Its content spans Qur’an studies, Arabic language, Islamic studies, examination coaching, schedules, learning modes, da’wah services, donations and registration.

The design needed to make that depth feel organised. Parents, students and adult learners should be able to understand what is available, find the right path and contact the institution without navigating a complicated system.

The approach

I grouped the content around the decisions a learner actually needs to make: what to study, who the programmes serve, how classes work, when they run and how to register.

A calm green and cream visual system gives the institution a credible educational identity, while modular programme cards and repeated calls to action keep the long page scannable. The registration form prepares a structured WhatsApp message, so the organisation receives useful details without needing a custom backend.

  • Programme paths for Qur’an, Arabic, Islamic studies and coaching
  • Online, physical, one-to-one and weekend learning modes
  • Flexible schedules and learner categories
  • WhatsApp registration with pre-filled student information
  • Mission, vision, values and institutional identity
  • Da’wah services, support options and contact details

The build

The frontend uses React components for repeated content such as programme cards, learning modes and value lists. Vite keeps development and deployment lightweight, while the interface relies on responsive CSS and accessible native form controls.

  • React
  • Vite
  • JavaScript
  • CSS
  • Lucide icons
  • WhatsApp deep links

The outcome

The result is a live, content-rich website that presents the institution as one connected learning experience. Visitors can compare programmes, understand teaching formats and move directly into a structured registration conversation.

Because the registration flow is built around WhatsApp, the team can start using it immediately while keeping the frontend simple to host and maintain.
