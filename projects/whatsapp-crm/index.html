GOJO.DEV WhatsApp CRM

A messaging dashboard and bot foundation designed to turn business WhatsApp enquiries into organised conversations, guided menus and useful quote requests.

The challenge

WhatsApp is a natural place for clients to ask questions, but a growing message history can make it difficult to track who contacted the business, what they need and where each conversation stands.

The goal is to build a useful layer around WhatsApp Business: store incoming messages, group them by contact, reply from a dashboard and guide new enquiries through clear service, portfolio, contact and quote options.

The architecture

The Express server handles webhook and messaging routes, while Mongoose models persist contacts, conversations and message records in MongoDB. The React dashboard retrieves that data, creates a unique chat list and filters the message stream for the selected contact.

The bot controller connects to the WhatsApp Business API and sends interactive list menus. Those menus give a visitor direct paths into services, portfolio links, contact details and a quote flow instead of relying on an unstructured first message.

  • Webhook foundation for incoming WhatsApp messages
  • MongoDB message and conversation storage
  • Conversation list grouped by contact
  • Dashboard replies through a send-message route
  • Interactive main menu and services menu
  • Structured states for multi-step bot conversations

The interface

The current React frontend uses a familiar two-panel messaging layout: recent conversations on the left and the selected message history on the right. It polls the backend for updates and includes a composer for replies.

The visual direction stays close to the dark, focused language of messaging tools while using GOJO.DEV green to make active states and important actions obvious.

  • React
  • Vite
  • Axios
  • Express
  • MongoDB
  • Mongoose
  • WhatsApp Business API

Current outcome

The repository now contains the core pieces of a working CRM foundation: data models, webhook and send routes, an interactive bot controller and a React conversation dashboard.

The next development stage is production hardening—authentication, stronger delivery and error states, real-time updates, search and clearer conversation status—before the tool is treated as a finished client product.
